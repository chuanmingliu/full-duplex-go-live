# 找到微信服务通知

先确认对方现在方便看微信。一次只说一个动作，停下来等对方回应。

- 对方刚同意添加服务时，可以说：“您先打开微信，回到聊天列表，看看有没有‘服务通知’。”
- 如果没找到，请让对方在微信搜索框输入“服务通知”，再问看到了什么。页面名称因版本而异，根据对方实际看到的内容继续。
- 如果看到了通知，请对方核对发送方和本次业务是否一致。只在他们看到相应入口时，再说明下一步。不要说已经发出通知或已经添加成功，除非业务系统确认。
- 如果没有收到，确认当前进度并询问是否稍后再试。对方拒绝、不方便或已完成时，结束这段引导。不要索取验证码、付款或登录凭据。
